# MANUS Medical Transportation Management V.19

마누스주 의료약품 운송 관리용 반응형 React 앱입니다. 별도 설치나 인터넷 연결 없이 압축을 푼 폴더의 첫 `index.html`을 열어 실행할 수 있습니다.

## 실행

- 즉시 실행: 압축 해제 후 최상위 `index.html` 열기
- 대체 실행: `dist/index.html` 열기
- 로컬 서버: `npm run dev`
- 빌드: `npm run build`
- 검증: `npm run verify`

데이터는 브라우저의 로컬 저장소에 보관됩니다. 운행 위치 화면은 실제 GPS와 연결되지 않은 시뮬레이션입니다.

재고 품목을 선택한 뒤 `선택 수량 삭제`를 누르면 품목별 삭제 수량을 지정할 수 있습니다. 현재 수량 전부를 삭제할 때만 해당 품목 행이 제거됩니다.

선박 상세에서 항로 A 또는 B를 선택하고 `운행 시작`을 누르면 선박이 Manus에서 출발해 지정된 섬을 순서대로 지난 뒤 Manus로 돌아옵니다. 순수 운항 시간은 두 항로 모두 60초이며, 중간 섬마다 10초씩 정박합니다. 따라서 항로 A는 총 100초, 항로 B는 총 90초가 걸립니다. 운행 위치 화면은 제공된 지도 위에 선박의 이동과 정박 상태를 표시하며, 섬을 선택하면 누적 도착·정박·출발 기록을 확인할 수 있습니다.

각 누적 운항 기록에는 초 단위 타임스탬프와 섬 이름이 표시됩니다. 기존 `YYYYMMDDHHmm_S_L` 식별 키도 함께 보존됩니다.

운행 위치 화면은 기본적으로 모든 항구의 기록을 최신 타임스탬프부터 표시합니다. 중간 섬마다 `도착`, `정박 시작 · 10초`, `출발` 시각이 기록되며, 지도에서 섬을 선택하면 해당 항구만 필터링할 수 있습니다. 선박 아이콘과 항로의 좌표는 제공된 지도에 표시된 8개 항구 표식의 중심 픽셀에 맞춰 표시됩니다.

재고 요청 화면에서 필요한 약품 이름과 수량을 입력하고 `요청하기`를 누르면 브라우저의 요청 내역에 저장됩니다. `요청 내역`에서는 저장 시각과 약품별 수량을 최신순으로 확인할 수 있습니다. 담당자 전송 기능은 아직 포함하지 않습니다.

지도상의 항로는 제공된 섬 중심점을 직선으로 연결한 시뮬레이션 경로이며 실제 해상 항로를 뜻하지 않습니다.
