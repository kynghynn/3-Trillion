# 양방향 국가 추천 기능: 자료 준비와 경량 설계 — 2026-11-05


목표
첫 선택을 고정한 채 두 번째 선택 국가와 비슷한 후보를 제시한다. 공여국→수원국 순서이면 수원국 후보, 수원국→공여국 순서이면 공여국 후보를 제시한다. 중심 기능의 규모를 키우지 않도록 설명 가능한 유사성 비교와 실제 관측된 분야 경험을 사용한다. 웹사이트는 구현하지 않았다.

실제 수집·정리한 자료
세계은행 공개 Indicators API에서 24개 수원국의 2020–2024 전력 접근률(EG.ELC.ACCS.ZS), 기초 식수 접근률(SH.H2O.BASW.ZS), 인터넷 이용률(IT.NET.USER.ZS)을 수집했다. 비결측 신규 관측은 340개다. 원 JSON과 URL·수집시각·SHA256 기록을 보관한다.
이전에 확보한 WDI의 소득 NY.GNP.PCAP.CD, 농촌 SP.RUR.TOTL.ZS, 인구 SP.POP.TOTL, UHC SH_UHC_SCI, 아동사망 SH.DYN.MORT를 재사용한다. 기준연도는 2023년으로 고정해 다른 연도의 최신값을 무작정 섞지 않는다. 24개국 모두 소득·농촌·인구·전력·UHC·아동사망·식수 값이 있고 인터넷은 19개국에 있다. 과거 공통연도 자료이며 현재 사업 수행 여건의 실시간 평가가 아니다.
GPEDC의 4개 역할별 공여자 협력관행 영역을 이용해 공여국 10개국의 비교 프로필을 만들었다. 값의 실제 관측기간은 각 프로필에 보존한다. 이 자료는 지원 분야의 전문성이 아니라 협력방식의 유사성을 보여준다.
기존 IATI 활동 6,371개에서 10개 공여국×24개 수원국×4개 분야 묶음(전체·보건·물·통신)의 경험 자료 960개를 만들었다. 호주처럼 국가와 분야가 거래별로 붙은 경우 동일 거래 안에서 연결했다. 활동이 여러 나라에 걸칠 수 있고, 발행기관·파일은 일부 표본이다. 활동수는 지원금액 비중이나 성공 정도가 아니다.
표준 분야명 연결을 위해 Code for IATI 공개 Sector JSON을 수집하고 IATI 공식 DAC 분야코드 문서와 대조했다. 제3자 미러가 제공하는 코드표라는 점을 기록한다. 분야분류는 코드 기반이며 문서의 실제 목적 확인을 대체하지 않는다.

수원국 추천
첫 선택 공여국 d, 두 번째 선택 수원국 r이면 r과 환경이 비슷한 r'을 찾고, 수집 표본에서 d–r'의 해당 분야 경험이 관측되는 경우 추천 후보로 남긴다. r 자체는 제외한다. 관계가 관측되지 않은 국가는 다른 탐색 화면에서 ‘신규 협력 검토’로 볼 수 있지만 이번 경험 기반 추천의 빈칸을 채우기 위해 관계를 만들어내지 않는다.
일반 환경은 소득(log), 농촌 인구 비율, 인구(log), 전력 접근성 4개를 동일가중으로 비교한다. 보건은 일반 환경 50%와 UHC·아동사망 50%, 물은 일반 환경 50%와 식수 접근성 50%, 통신은 일반 환경 50%와 인터넷 이용률 50%다. 이 가중치는 정책적 초안이며 통계적으로 학습한 최적계수는 아니다.
소득·인구의 로그변환은 극단적인 규모 차이가 거리를 지배하지 않게 한다. 정규화는 고정된 24개국 참조집단의 10·90백분위 경계로 0–1 환산 후 범위 밖은 절단한다. 현재 구현의 분위수는 정렬 후 인덱스 round((n−1)×p)를 사용하는 최근접 순서통계 규칙이다. 필터를 바꿀 때 참조집단을 다시 맞추지 않는다. 공개할 때 참조집단 변경은 데이터 버전 변경으로 기록한다.
유사도 = 100 × (1 − Σ w_j |z_rj − z_r'j|).
100은 선택 변수상 같다는 뜻이고 사업 적합성 100점이나 성공확률이 아니다. 절단으로 극단값의 차이가 줄어드는 한계가 있다. 실제 값도 함께 저장했다.
해당 분야 패널의 필수값이 하나라도 없으면 점수를 계산하지 않는다. 분야에 따라 관측 항목이 다른 두 점수를 같은 범례로 직접 비교하지 않는다. 빈칸을 0이나 국가 평균으로 채우지 않는다.

공여국 추천
첫 선택 수원국 r, 두 번째 선택 공여국 d이면 GPEDC의 4개 공여자 협력관행 점수가 d와 비슷한 d'을 찾는다. 수집 표본에서 d'–r의 해당 분야 경험이 있는 후보를 남기고 d 자체는 제외한다.
유사도 = 100 − 네 영역 점수 차이 절댓값의 평균.
4개 영역은 이미 0–100 척도이므로 표본 순위나 기관별 ATI 점수와 섞지 않는다. 공여국의 활동수 분포는 수집 범위가 달라 국가 전문성 벡터로 사용하지 않는다. 독일·미국도 협력관행 비교 프로필은 있으나 이번 수집에서 분야별 활동 파일이 없으므로 경험 기반 후보에 자동 포함되지 않는다. 이는 협력 의지나 역량이 없다는 판정이 아니다.

웹페이지에 제공할 자료
recipient_profiles.json: 24개국×8개 변수의 값·연도·출처·결측·정규화.
donor_profiles.json: 10개 공여국의 협력관행 영역과 보고기간.
bilateral_sector_experience.json: 국가쌍·분야의 활동 ID와 표본수.
similarity_pairs.json: 양방향 프로필 비교에 사용할 2,298개 유사성 행.
recommendation_previews.json: 공여국 10×수원국 24×분야 2(전체·보건)×선택방향 2 = 960개 맥락의 최대 3개 후보. 그중 840개는 후보가 있고 120개는 표본 내 협력 또는 비교자료가 부족하다.
추천 이유는 가까운 변수 두 개, 유사도, 해당 분야 관측 활동수를 포함한다. 활동수에 가점을 주지는 않고 경험 확인 조건으로만 사용한다. 이 순서는 예측 케미 순위가 아니다.

예상 케미와의 관계
현재 예측 케미 학습에 적합한 공통 평가척도·대표 표본·시간 검증이 부족하므로 predicted_chemistry는 null이다. 이번 기능은 사용자가 요청한 두 선택지 중 ‘사업 환경 또는 공여자 협력관행이 유사한 후보’로 구현할 수 있다. 나중에 검증된 예측 모형이 생기면 별도 카드와 범례로 추가한다. 유사도를 케미로 이름만 바꾸지 않는다.
국가 평균에서 파악하기 어려운 도서지역 물류·조달·제도 변화는 개별 사업 검토에서 확인해야 한다. PNG를 추천 상단에 고정하거나 특정 공여국을 우대하는 규칙은 없다. 보건 성과가 낮다는 이유만으로 유사성이 사업 수요나 지원 우선순위를 결정하지 않는다.

검증과 공개 범위
역할별 후보 유형, 자기 자신 제외, 첫 선택 국가 고정, 실제 관측 경험 연결, 미검증 예측값 비움, JSON 형식과 원자료 메타데이터를 확인했다. 시연용 비교집단에서 만든 설명 가능한 예시이며 추천 성과를 외부 검증한 결과는 아니다.
원자료·가공 JSON·수집 및 가공 코드·다운로드 기록을 저장했다. 저장소에는 이번 자료와 51afdaf 이후 지표 v0.3 분석·보완 자료를 함께 기록한다. 대용량 제3자 평가 PDF와 원문 추출 텍스트는 로컬에 보관하고 출처·해시·필요한 가공 결과를 게시한다.
