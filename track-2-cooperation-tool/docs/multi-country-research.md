# 트랙2 다국가 확장 연구·데이터 준비 v0.2

작성일 2026-11-04 / 웹사이트 제작 전 연구용 자료
이 문서는 기존 v0.1의 한국 중심 수집 범위, ATI 미확보 상태, 권장 시연 경로를 갱신한다. v0.1의 측정상 주의사항은 유지한다.

1. 이번에 확정한 범위
최종 서비스는 특정 공여국에 제한하지 않는다. 국가를 먼저 선택한 뒤 공여/수원 역할을 고를 수 있고, 양쪽 역할을 가진 국가는 양쪽 자료를 따로 표시한다. 국제기구는 국가와 다른 유형으로 구분한다. 최종 확장은 ‘모든 관측된 협력관계’를 목표로 하되, 공개자료가 없다는 이유로 협력이 없었다고 판정하지 않는다.

이번 시제품용 수집 범위는 공여국 10개 × 수원국 24개, 총 34개국이다.
공여국: 호주, 뉴질랜드, 일본, 한국, 영국, 캐나다, 프랑스, 스웨덴, 독일, 미국.
수원국: 파푸아뉴기니, 솔로몬제도, 바누아투, 피지, 사모아, 통가, 동티모르, 베트남, 캄보디아, 라오스, 인도네시아, 필리핀, 방글라데시, 네팔, 파키스탄, 스리랑카, 케냐, 탄자니아, 우간다, 르완다, 가나, 세네갈, 에티오피아, 미얀마.
태평양 도서국의 보건 접근 문제를 충분히 담으면서 아시아·아프리카 비교도 가능하도록 선정했다. 세계 대표 무작위 표본은 아니며 공여국은 DAC 중심이다. 중국·인도 등 남남협력 제공자를 최종 서비스에서 배제한다는 뜻이 아니다.

2. 실제 확보·구조화한 자료
가. 8개 공여국 소속 발행기관의 IATI XML에서 선택 수원국과 연결된 고유 활동 6,371개를 추출했다.
한국 KOICA 1,342 / 뉴질랜드 MFAT 1,168 / 영국 FCDO 1,058 / 호주 872 / 캐나다 811 / 프랑스 AFD 752 / 일본 JICA 225 / 스웨덴 Sida 143.
이는 이번에 선택한 24개 수원국에 해당하는 활동수다. 각 국가의 전체 원조사업 수가 아니다. 원래 KOICA 스냅샷의 2,600개와 모순되지 않는다.
영국은 20개 분할 파일 중 5개, 캐나다는 일부 진행·종료 파일, 스웨덴은 한 분할 파일을 수집했다. 일본은 JICA, 한국은 KOICA, 프랑스는 AFD라는 기관 범위의 한계가 있다. 독일·미국은 이번 확장에서 IATI 사업 파일을 확보하지 않았고 GPEDC·국가 배경자료로 포함했다. 비교 화면에 수집 범위를 반드시 붙인다.

나. 240개 가능한 국가쌍 중 210개에서 수집한 GPEDC 또는 IATI 자료로 관계가 관측된다. 나머지 30개는 ‘이번 표본에서 미관측’이다. ‘원조 전력 없음’이 아니다. GPEDC 국가쌍·라운드 행은 765개이며, 이 중 2026 발간 라운드는 79개다. 765개가 모두 최근 조사라는 뜻이 아니다.
실제 보고기간을 reporting_year에서 별도 연결했다. 예를 들어 호주–솔로몬제도 2026 라운드는 2024년 보고기간이다. PNG 관련 최신 GPEDC 라운드는 확보 범위에서 2018이므로 현시점 등급을 보간하지 않는다.

다. 선택 34개국 중 최신 GPEDC 기반 연구용 역할별 등급은 공여국 10개와 수원국 14개, 총 24개다. 나머지 수원국에 임의 등급을 채우지 않았다. 이 등급은 새 모델의 시험값이며 외부 인증 등급이 아니다.

라. IATI actual 요소를 가진 원관측값 3,287개를 구조화했다. 호주와 프랑스 자료에서 추출되었으며, 평가척도·단위·연도·성과단계가 섞여 있어 합산하거나 기관 간 직접 평균하지 않는다. actual은 ‘발행기관이 보고한 값’이지 독립 검증된 인과적 효과라는 뜻이 아니다.
호주의 단일 수원국 보건활동에 대해 평가기준·기간별 248개 관측값을 별도 추출했다. 이는 248개 사업이 아니다. 10개 수원국의 최근 관측 효과성 평가 분포도 만들었다. 세부 분야는 OECD DAC 121/122/123/130 계열을 보건·인구·생식보건 묶음으로 사용하며, 임상 보건만으로 해석하지 않는다.

마. PWYF ATI 2024의 공식 결과 XLSX를 확보해 51개 기관 평가를 JSON으로 바꿨다. 기존의 ‘다운로드 실패’ 상태는 해소되었다. 총점과 가중 구성항목 점수를 원형대로 보존했다. 기관 점수를 해당 국가 전체 점수로 자동 복사하지 않는다. 2026 방법론을 2024 원점수에 소급 적용하지 않는다.

3. 접근 제한에 대한 대체 경로와 검증
Code for IATI의 공개 레지스트리 미러에서 데이터셋·발행기관 메타데이터를 받고, 그 안의 실제 발행기관 주소에서 XML을 내려받았다. 이 경로로 여러 국가 자료를 확보했다. 미러는 검색·발견 수단이고 OECD CRS 전체의 복사본은 아니다.
PWYF는 2024 페이지의 Results Data 다운로드 경로로 정상 XLSX를 확보했다. 단순 파일 확장자만 보지 않고 실제 ZIP/XLSX 내용과 시트 구조를 확인했다.
DFAT 평가 PDF는 공개 웹 열람으로 내용을 검토했지만 직접 파일 저장은 HTTP 오류·시간초과로 실패했다. 따라서 ‘PDF 보관 완료’로 기록하지 않는다. 정확한 원문 주소, 페이지, 짧은 연구메모를 web_review_notes.json에 저장했다. 각 IATI 활동에도 원문 평가 링크가 남아 있다.
솔로몬제도 정부의 2025 보건협력 안내 HTML은 다운로드 성공 응답 뒤 실제로는 자바스크립트 확인 화면이었다. 본문 확보로 세지 않았다. 대신 같은 정부의 사업 자문관 TOR PDF는 정상 확보했다. 이 문서로 2025–2028 사업의 기간·규모·방향을 교차확인할 수 있다. TOR는 성과평가가 아니다.
파일명 jica_png_health.pdf는 내용을 확인하니 Port Moresby Sewerage System Upgrading Project 관련 평가였다. 보건 임상사업으로 쓰지 않고 하수도·WASH/인프라 사례로 재분류했다. 파일명 추정만으로 분야를 판정하면 안 되는 사례다.
OECD CRS 대규모 원자료, Lowy 전체 다운로드는 여전히 확보 완료로 간주하지 않는다. Lowy 웹 방법론과 자료 활용 가능성은 검토했지만 해당 총액을 다른 자료와 합산하지 않는다. ODA/OOF, 약정/지출, 불변가격/당해가격 차이를 맞춰야 한다.

4. 여러 자료를 복합적으로 쓰는 원칙
같은 자료를 국가등급, 배경조건, 국가쌍 설명에 함께 쓰는 것은 가능하다. ‘한 자료는 한 용도’라는 제한을 두지 않는다. 핵심은 같은 관측값에 점수를 중복 부여하거나 서로 다른 개념을 같은 척도로 취급하지 않는 것이다.
예를 들어 GPEDC 국가 전략 항목을 수원국 등급에 반영하면서 해당 국가의 배경 설명에도 다시 보여줄 수 있다. 공여국의 협력관행 평균과 그 평균의 일부인 특정 국가쌍 관측값도 각각 볼 수 있다. 그러나 두 값을 독립된 성과처럼 케미 총점에 함께 더하면 중복이다.
향후 국가 역량을 케미 예측에 넣을 경우 해당 국가쌍을 뺀 나머지 협력경험으로 국가 평균을 만들고, 예측 시점 이후의 자료를 차단해야 한다. 공여국·수원국·사업별로 겹치는 집단을 고려해 검증해야 한다. 지금 수집량으로 검증된 예측 성공률을 주장하지 않는다.

권장 활용 조합:
- GPEDC: 역할별 협력관행 등급 + 쌍별 공동 이행 배경 + 제도적 환경 설명.
- IATI: 사업목록 + 분야별 경험 + 거래 내역 + 계획·평가 문서 발견 + 보고된 성과.
- ATI: 기관별 공개 역량 + 등급의 공개성 하위영역을 보완할 후보 + 자료 접근성 설명.
- WGI/SPI/OBS/CPIA: 실행 여건 + 유사성 특징 + 외부 검증 + 별도 역량모델 후보.
- QuODA/CDI: 구성개념 설계와 역사적 비교. 이미 GPEDC·ATI를 포함한 총점을 다시 더하지 않음.
- 국가 보건계획·평가보고서: 정책 정합성 + 공동 이행 + 실제 성과 + 지속성 + 새 사업의 설계 교훈.
- CRS/Lowy/AidData: 사업 규모·분야 특화·비교 분모 보완 후보. 수집·단위 대조가 끝난 범위에서만 계산.
세부 규칙은 processed/source_reuse_matrix.json에 기계판독 형태로 저장했다.

5. 국가등급의 선택과 추가 지표 도입 조건
기본 등급은 ‘개발협력 관행’으로 명확히 정의하고 기존 GPEDC 4영역 동일가중 모델을 유지한다. 여러 출처의 총점들을 평균하는 방식보다 측정 대상이 분명하다. 기관 공개성·국가 행정역량까지 합친 ‘협력 실행 준비도’가 필요하면 별도 모델로 이름과 가중치를 명시해야 한다. 두 개념을 같은 이름 아래 몰래 바꾸지 않는다.
절대/상대 방식은 문항상 기준에 따른 0–100 점수를 기본으로 하고 동료국 내 위치를 보조로 제시하는 조합을 권장한다. 다만 현재 12개 등급의 동일 폭 구간은 시제품 규칙일 뿐 정책적으로 검증된 절대 기준은 아니다. 모든 나라를 강제로 12등분하는 상대등급은 작은 표본 변화로 등급이 흔들리고 절대 개선을 가릴 수 있어 기본안으로 채택하지 않는다.
공여국과 수원국은 역할별 구성요소가 다르므로 같은 등급끼리 ‘누가 더 좋은 국가인지’ 직접 비교하지 않는다. 낮은 소득·보건 취약성은 지원 수요이며 협력 의지 부족과 구분한다.
추가지표 채택 전에는 측정 개념·시점·평가단위 일치, 원천 중복, 결측의 구조, 지표 간 상관, 가중치·정규화 민감도를 확인한다. 상관이 높다는 이유만으로 삭제하거나 낮다는 이유만으로 채택하지 않는다. 반영할 독립된 내용이 있는지가 먼저다.
ATI는 여러 기관이 있는 나라의 일부 기관만 평가하므로 국가대표 가중치와 기관별 전체 지원비중이 없는 현재 단계에서는 등급 총점에 자동 결합하지 않는다. WGI 등도 본래 협력관행과 다른 개념이므로 기본등급의 빈칸을 대체하지 않는다.

6. 케미의 산출 방법과 현재 가능한 화면
평가 단위는 ‘공여국–수원국–분야–기간’이다. 4영역은 정책 정합성 30, 공동 이행 30, 성과 25, 지속성 15를 초기 제안으로 유지한다. 문헌으로 최적 가중치가 검증된 것은 아니다. 동일가중 및 영역별 가중치 변경 결과를 함께 검토한 후 공개해야 한다.
자료선택은 분야별 국가계획과 사업목표, 공동 검토·이행보고서, 완료·독립평가의 outcome, 종료 후 운영·예산·인력 자료로 한다. 실측 성과와 평가자의 판단, 미래 지속 가능성의 전망과 실제 지속을 분리한다. 누락을 0점이나 중간점으로 채우지 않는다.
성과척도는 기관 원점수를 먼저 보존한다. 호주 1–6 평가, KOICA 1–4 등의 숫자를 최소·최대만 맞춰 같은 척도로 바꾸지 않는다. 공통 판단기준 0/1/2의 각 단계에 해당하는 근거 문장을 기록하고 2인 독립 코딩으로 확인한다. 기관별 기준 연결표와 예시를 만든 뒤 일치도를 점검한다.
사업 평균은 개입 단위별 동일가중을 기본, 금액가중은 민감도 비교로 둔다. 같은 대형사업의 여러 연차보고서·하위활동을 독립 사업으로 중복 집계하지 않는다. 공동재원 사업의 성과를 모든 공여국이 각각 독자적으로 창출한 것처럼 표시하지 않는다.
완성 케미의 공개 조건은 같은 분야에서 식별되는 평가사업 3건 이상, 종료연도 2개 이상, 4영역 근거 충족이라는 초기 품질관리 규칙이다. 이 숫자는 통계적 충분성을 보증하지 않는다. 현재 전체 케미 종합점수는 산출하지 않았고 모두 null이다.

그렇다고 지도와 상세 화면에 아무것도 표시할 수 없는 것은 아니다. ①관계와 분야별 활동, ②GPEDC 협력관행 원항목, ③실제 사업평가 분포, ④평가문서와 교훈은 실제 자료로 표시할 수 있다. 이때 화면 이름을 ‘케미 근거’ 또는 ‘관측 사업성과’로 표시하고 종합 케미와 구분한다. 서로 다른 지표로 색칠한 지도를 하나의 케미 범례로 섞지 않는다.
호주 자료에서 단일 수원국 보건투자의 2025-06-30 종료 평가기간을 예로 들면 PNG는 효과성 평가 7개 활동 중 5개가 4점 이상이다. 이는 이번 수집·분류 조건의 관측치이며 성공확률 71.4%가 아니다. 솔로몬제도는 같은 기간 1개만 남으므로 ‘케미 100점’으로 표시해서는 안 된다. 표본 3개 미만은 비율 강조를 끄고 원평가와 사업명을 보여주는 편집 규칙을 저장했다.
평가 대상은 선택되어 있다. DFAT 공식 설명상 일정 규모 미만, 초기 단계, 일부 유형 등은 평가에서 제외될 수 있다. 평가 없는 사업을 실패로 계산하지 않는다. 해당 분포는 독립평가의 대표 표본도 아니다.

7. 권장 시연: 호주 → 솔로몬제도 → PNG → 트랙1
(1) 발표자는 호주의 개발협력 담당자 역할로 세계지도에서 호주를 선택한다. 뉴질랜드·일본·한국 등으로 바꿔도 같은 화면 구조가 작동함을 짧게 보여준다.
(2) ‘보건’을 고르면 관계와 자료가 있는 상대국을 확인한다. 이번 파일에서 호주–솔로몬제도는 178개 관련 활동 중 43개, 호주–PNG는 245개 중 72개가 보건 분류와 연결된다. 다국가 활동을 포함한 관여 건수로, 상호 배타적 사업 수나 성과 우열이 아니다.
(3) 솔로몬제도 HSSP Phase 3을 열어 실제 연차평가와 독립평가 링크를 확인한다. 최고 케미 국가라서 고르는 것이 아니라 분야 경험과 검토할 근거가 있어 선택한다. 2016–2024 사업과 2025–2028 후속 사업을 구분한다. 2025년 기간의 평가는 원문 기간으로 그대로 표시하며 사업 종료연도와 임의로 맞추지 않는다.
(4) 독립평가가 보여주는 공동계획·예산·예측 가능성의 장점과 한계에서 ‘원격 지역의 서비스와 공급체계’라는 새 사업 검토 문제로 넘어간다. 모든 공여자가 함께 참여한 SWAp 결과를 호주 단독 성과로 말하지 않는다.
(5) 상세 하단에 ‘관련 과제를 검토할 국가’ 카드로 PNG를 제시한다. 이는 태평양 보건 서비스·주정부 전달체계·접근성이라는 공통 정책문제를 토대로 연구자가 선정한 검토 경로다. 통계적 최근접 국가나 예측 케미 1위라고 부르지 않는다. 바누아투·피지·동티모르 등 다른 검토 후보도 함께 보여줄 수 있다.
(6) PNG의 PATH/AIHSS 사례를 열어 기존 협력경험과 취약점을 함께 본다. 기존 프로그램에서의 성과가 마누스 의약품 해상 공급망의 성공을 보장하지 않으며, 국가 평균과 다른 주의 결과를 마누스 실측자료로 대체하지 않는다.
(7) 발표자가 확인된 보건 수요와 현장 추가조사 과제를 설명하고 PNG 마누스 시범사업을 ‘검토 대상’으로 선택한다. 트랙1에서 의약품 품절률, 정시 배송률, 주문 충족률, 재고정확도, 단위배송비, 현지 운영재원·인력 등 별도 사업지표와 타당성 검증을 설명한다. 트랙2는 국가·협력경험 탐색, 트랙1은 구체적 사업설계라는 역할이 자연스럽게 이어진다.

대안: 뉴질랜드 → 솔로몬제도/바누아투 → PNG 예방접종·보건체계 사례. MFAT 원자료와 PNG 관련 3개 사업을 준비했다. 성과값 부족으로 정량 지도보다는 사업·문서 탐색 시연에 더 적합하다. 한국→베트남 경로도 보조사례로 유지하되 PNG 유사성 순위를 강제로 만들지 않는다.

8. 지도·상세 화면을 만들 때 사용할 자료
국가: processed/countries.json, country_ratings.json, country_context.json.
관계·범위: coverage_matrix.json, pair_process_observations.json.
활동·문서·거래: activities.json. 거래금액은 통화·날짜·거래유형을 보존한 원자료이며 아직 검증된 국가쌍 총액이 아니다.
결과: result_observations.json. 호주 보건 원평가: australia_health_rating_observations.json. 분포: australia_health_performance_preview.json.
시연용 7개 활동: demo_project_evidence.json. 기관 공개성: ati_2024_agencies.json.
계산·출처 활용: data_contract.json, source_reuse_matrix.json, methodology_v0.2.json, web_review_notes.json.

선택과 표시: 공여국·수원국 어느 쪽에서 시작해도 같은 관계를 탐색한다. 자료부족 국가를 선택 불가 처리하지 말고 부족 사유를 보여준다. 지도 색은 점수, 무늬·별도 표식은 자료부족에 사용한다. 작은 도서국은 검색목록과 확대 지도로 보완한다. 예측값이 생기더라도 관측값과 다른 탭·범례를 쓴다.
재정집계: 약정·집행·지출을 분리하고 통화·가격기준을 맞춘다. 활동 수준의 국가와 분야 비율이 명확할 때만 배분한다. 여러 국가가 있는 활동에서 비율이 없으면 균등 배분하지 않는다. 거래에 국가·분야가 붙은 호주 자료는 같은 거래 안에서 두 코드를 연결한다. 지역 코드만 있는 사업을 임의 국가에 배정하지 않는다.

9. 준비 완료 범위와 남은 검증
완료: 다국가 원자료 확보, 기관·국가쌍·활동·기간 연결, 실제 평가 관측값 추출, 기관 투명성 자료 회수, 자료 복합 활용 규칙, 비교 가능한 시연 경로, 지도 데이터 구조. 웹사이트는 만들지 않았다.
미완료: 모든 국가의 포괄적 원조 전력, 비교 가능한 전 세계 금액 총계, 기관 평가척도의 검증된 연결, 4영역 케미의 독립 코딩과 타당화, 추천 알고리즘의 외부 검증. 이 단계에서는 ‘데이터 탐색과 근거 확인이 가능한 연구 시제품’이라고 소개하는 것이 정확하다.
이번 작업은 일부 국가 몇 개를 추가한 수준을 넘어 다양한 공여국과 24개 수원국을 탐색할 수 있게 한 자료 준비다. 동시에 수집 파일이 많은 것을 완성된 평가모델과 혼동하지 않도록 각 파일에 범위와 결측을 남겼다.
